### 💼 Professional Journey

<details open>
<summary><b>1. PT EbyB Global Marketplace — Full Stack Engineer</b> <i>(September 2026 – Present | Yogyakarta, Indonesia)</i></summary>
<br/>

- **Google Ads Automation Engine:** Architected and deployed an enterprise ad automation engine using **Go (Golang)**, **Gin**, and **PostgreSQL**, automating multi-account campaign auditing and budget realignments via **Google Ads API v25 & GAQL**.
- **TikTok Marketing API Microservice:** Built a high-throughput microservice integrating **TikTok Marketing API (v1.3)** to manage multi-tenant advertising entities (Campaigns, AdGroups, Ads, and Creatives).
- **Closed-Loop 1-Tap AI Action System:** Implemented LLM function calling to convert diagnostics into safe real-time mutations (negative keywords, zero-sum budget reallocations) protected by strict financial risk controls.
- **Symmetrical Impact Measurement Engine:** Formulated a before-vs-after comparison engine using PostgreSQL JSONB; **cut client wasted ad spend by 16.5% (~Rp 1M/week on test campaigns)** and eliminated **100%** of irrelevant search traffic.
- **Concurrency & Idempotency:** Designed dual processing modes (**async HTTP 202 polling workers vs. sync HTTP 200**) with conflict-handling locks and achieved **100% unit & integration test coverage**.
- **Zero-Throttle Sync:** Established a 15-minute timezone-resilient synchronization pipeline handling high-volume daily metrics without hitting API rate limits.
</details>

<details open>
<summary><b>2. PT Hino Motors Manufacturing Indonesia — Software Engineer Intern</b> <i>(August 2025 – February 2026 | Purwakarta, Indonesia)</i></summary>
<br/>

- **Enterprise Sales Order Digitization:** Built a web-based Sales Order Information System using **ASP.NET Core v8 (MVC), C#, SQL Server, and DevExtreme**, replacing legacy multi-file Excel workflows for international service parts.
- **Workflow & Lead Time Reduction:** Streamlined the order fulfillment lifecycle by **54.5% (slashing operational steps from 11 manual stages to 5 digital stages)** and reduced order drafting time by **~90% (from 20–30 mins to <3 mins)** via automated master-data validation.
- **Hierarchical Approval:** Digitized a 2-tier approval workflow across Department Head and Division Head levels featuring Role-Based Access Control (RBAC), rejection audit logs, and automated SMTP email dispatching.
- **Extreme Caching Optimization:** Built an `IMemoryCache` analytical layer that **slashed query latency by 99.08% (from 976 ms to 9 ms)** and boosted throughput by **2,744% (up to 412 req/s)** with a 0.00% error rate under load testing.
- **Frontend Performance:** Achieved a near-perfect **99/100 Google Lighthouse Performance Score** (FCP 0.58s, LCP 0.70s, TBT < 70ms) on data-heavy virtualized DataGrids.
- **Stakeholder Acceptance:** Facilitated iterative User Acceptance Testing (UAT) with division leadership, achieving a **98.7% overall acceptance rate**.
</details>

<summary><b>3. Senyumin (Denteksi) — Web Developer Intern</b> <i>(August 2024 – January 2025 | Yogyakarta, Indonesia)</i></summary>
