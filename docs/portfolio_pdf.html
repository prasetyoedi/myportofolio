Managing high-velocity advertising across TikTok Ads and Google Ads required constant manual intervention by media buyers, suffered from unoptimized wasted budget on irrelevant search terms, and lacked centralized telemetry due to disparate API rate-limiting rules.

The Architectural Solution

Architected Go (Gin) backend microservices integrating Google Ads (GAQL v25) and TikTok Marketing API (v1.3) with async worker queues, conflict-handling distributed locks, and a Closed-Loop 1-Tap AI Action engine protected by strict financial risk guardrails.

Section 03 · Enterprise Deep-Dive Case Study 2 ASP.NET Core v8 · SQL Server · DevExtreme · IMemoryCache

Service Parts Sales Order System with Digital Multilevel Approval

PT Hino Motors Manufacturing Indonesia · August 2025 – February 2026 | Enterprise Internship & Final Project
99.08% Latency Cut · 98.7% UAT

The Engineering Challenge

International service parts sales orders previously relied on manual physical paper routing across 11 stages and 3 management tiers. This caused drafting delays (20–30 mins/order), untracked order states, and 976ms analytical database queries on massive historical order catalogs.

The Architectural Solution

Architected a centralized ASP.NET Core v8 (MVC) enterprise system featuring a 2-tier RBAC approval state machine (Staff PIC → Dept Head → Div Head), automated master-data validation, and an IMemoryCache analytical layer with DevExtreme virtualized DataGrids.
